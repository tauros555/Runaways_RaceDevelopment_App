# Race Development v6.4 — 出馬表参照仕様

## 正式入力
Race Developmentは出馬表CSVをブラウザからアップロードしません。

常に:
`data/調教判定表.csv`

を参照します。

このCSVはRunaway's本体が「読み込む側」の調教判定表と同じデータ形式です。

## 添付CSVで確認した実列
行数: 649
列数: 89

Race Developmentが出馬表として必須利用する列:
- 年月日
- 場所
- R
- 馬番
- レース名
- 芝・ダ
- 距離
- 馬名
- 騎手
- 枠
- 血統登録番号

利用可能な補助列:
- 性別
- 調教師
- 所属
- 父
- コースID
- ZI
- 脚質
- 本命候補判定
- 相手候補判定
- 地雷ラップ判定

## Simulatorへの入力方針
調教判定表は「今回走る馬を特定する出馬表データ」として使用します。

Runaway's側の:
- 調教判定
- 本命候補判定
- 相手候補判定
- 地雷ラップ判定
- その他調教評価

はRace Simulatorの予測特徴量には加えません。
必要なら最終画面の参考表示としてのみ利用します。

## キー
馬:
`血統登録番号`

今回レース:
`年月日 + 場所 + R`

CSVの`レースID`はExcel経由で浮動小数/指数表記になる可能性があるため、
current raceの主キーには使用しません。

## 毎週の更新
ローカル/GitHub/Drive同期など、どの方法でも
`data/調教判定表.csv`
を最新版に差し替えるだけです。

アプリ再起動後、そのCSVから対象レース一覧を自動生成します。
