# v6.9 距離変化補正 復活実装

## 入力
各馬の過去履歴から直近前走の距離を取得。

`DistanceChange = 今回距離 - 前走距離`

区分:
- 短縮400m+
- 短縮200-399
- 短縮1-199
- 同距離
- 延長1-199
- 延長200-399
- 延長400m+

## 補正マスタ
`data/DistanceChangeCorrectionMaster_v1.csv`

2024-2025のQueuePredictor残差から階層補正を作り、2026ホールドアウトで重みを再検証。

階層:
1. COURSE = 場所×芝ダ×今回距離×距離変化
2. SURFACE_DISTANCE = 芝ダ×今回距離×距離変化
3. GLOBAL = 距離変化区分

## 本番重み
- LeadProb: 0.4
- 初角位置: 1.0
- 勝率独立補正: 0.3

勝率補正は、距離変化がLead/初角を介して既に勝率へ間接反映されるため弱く設定し、二重加点を抑制する。

## Runaway's本体との分離
本補正はRace Developmentの隊列・勝率シミュレーション専用。
Runaway's本体のVer7最終スコアには加点しない。
