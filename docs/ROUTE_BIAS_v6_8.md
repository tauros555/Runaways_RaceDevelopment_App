# Race Development v6.8 — 前後位置 × 内外位置 × 馬場バイアス

## 隊列UI
表示場面は2つだけ:
1. 初角
2. 最終コーナー

横方向:
- 初角: ハナ / 先行 / 好位 / 中団 / 後方
- 最終角: 先頭 / 先行 / 好位 / 中団 / 後方

縦方向:
- 内
- 中
- 外

## 進路推定
初角は主に:
- 枠位置
- LeadProb
- 初角位置
- FirstTurnPressure

最終角は:
- 初角進路
- 最終角位置
- ClosingOpportunity
- 位置上昇
- 枠位置

からヒューリスティックに推定。

これは「実際の走行レーンの教師ありモデル」ではないため、
UI上は予測進路として扱う。

## 馬場・進路バイアス
選択:
- AUTO
- 内有利
- やや内有利
- フラット
- やや外有利
- 外有利

AUTO:
コースマスタの `参考枠傾向` に明示的な根拠がある場合のみ使用。
「重/不良なら自動的に外有利」のような一般化は行わない。

手動:
当日の芝の傷み・内伸び・外差し等を見てユーザーが変更可能。
手動がAUTOより優先。

## 補正
最終コーナー進路と有利想定が一致した場合、最大+4pt。
逆なら最大-4pt。
正式なRunaway's本体スコアには混ぜない。
Race Development内のMonte Carlo基礎強度にのみ反映。

画面には:
- 恩恵＋＋
- 恩恵＋
- 影響小
- 不利－
- 不利－－
を表示する。
