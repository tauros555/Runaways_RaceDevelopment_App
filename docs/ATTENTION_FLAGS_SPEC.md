# Race Development v6.5 注目フラグ仕様

調教判定表から、以下の3条件をRace Development画面で明示します。

1. `本命候補判定` が 〇
2. `地雷ラップ判定` が 〇
3. `前日坂路時計` が 66秒台以下

## 前日坂路の判定
`<= 66.99秒`

つまり66.0〜66.9秒台、およびそれより速い時計を該当とします。

## 表示
各馬について複数同時表示可能。

例:
`5 ○○ホース　本命候補〇 / 前日坂路65.8秒`

3条件すべてに該当する場合:
`本命候補〇 / 地雷ラップ〇 / 前日坂路66.2秒`

この注目表示は **Race Simulatorの予測特徴量には加えません**。
調教判定表からの参考情報としてUIで可視化するだけです。
