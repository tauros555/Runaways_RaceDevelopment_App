# Runaway's Race Development 運用手順

## 1. 初回起動
Windowsの場合:

1. `install_windows.bat` を1回実行
2. `start_windows.bat` を実行
3. ブラウザでStreamlit画面が開く

Mac/Linux:

```bash
pip install -r requirements.txt
./start_mac_linux.sh
```

## 2. 毎週のデータ更新
`🔄 TARGET年度更新` タブへ、その年のTARGET馬単位CSVを丸ごとアップロード。

主キー:
`race_key × 血統登録番号`

- 新しい行 → INSERT
- 同一行 → SKIP
- TARGET側で内容修正 → UPDATE

更新すると `data/history_master.csv.gz` が作成され、以後そちらを優先利用します。

## 3. レース予測
`🎯 レース予測` タブへRunaway's判定表をアップロード。

Race Developmentは判定表から今回の出馬表情報を取得します。
Runaway's最終評価・最終スコア・調教評価は画面で併記できますが、Simulatorの隊列/展開予測入力には混ぜません。

日付 → 開催場 → R を選択すると自動計算します。

## 4. 表示内容
- LeadCompetition / 先行圧力
- SLOW / EVEN / HIGH / SPRINT_FINISH / LONG_SPURT
- AUTO / 手動シナリオ
- スタート→初角→3角→4角 馬群図
- 騎手位置取り補正
- 動き予測（↑進出 / ↓後退）
- 展開評価 ◎○△×
- Monte Carlo 1000 / 5000 / 10000回
- MC勝率 / 連対率 / 複勝率
- 4角3番手内率
- シナリオ別勝率
- 位置関係の共存参考

## 5. 注意
Streamlit Community Cloudなどの一時ファイル環境では、アプリ内で生成した `history_master.csv.gz` は再起動時に永続保存されない場合があります。
クラウド本番化時はGitHub/外部ストレージ/DBのいずれかへ履歴を永続化する設計へ変更してください。
