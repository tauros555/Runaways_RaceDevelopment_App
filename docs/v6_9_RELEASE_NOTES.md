# Race Development v6.9.0

## 重要修正: 血統登録番号の履歴結合
調教判定表では血統登録番号が8桁短縮形になるケースを確認。
例:
- 調教判定表: `23106616`
- history_seed: `2023106616`

旧版では文字列が一致せず、今回馬の過去履歴が0件扱いになるケースがあった。

v6.9では8桁の場合に内部で10桁へ正規化し、
`history_seed/history_master` の `血統登録番号` と正しく結合する。

実サンプル確認:
- 中山9R 16頭
- 旧版: 過去履歴一致 0/16
- 修正版: 過去履歴一致 16/16

## 距離変化補正の復活
前走距離を過去履歴から取得し、
`今回距離 - 前走距離` をコース別補正へ使用。

本番重み:
- LeadProb: 0.4
- 初角位置: 1.0
- 勝率独立補正: 0.3

補正階層:
1. 場所×芝ダ×今回距離×距離変化
2. 芝ダ×今回距離×距離変化
3. 距離変化区分全体

- 参照階層
- 学習N
